# Playground provider logos

Use the company artwork at its original aspect ratio and colors. The white backing in the Playground keeps dark marks visible without recoloring the files.

Assets updated September 6, 2026:

- `cohere.svg`: compact, full-color company mark downloaded unchanged from [Cohere](https://cohere.com/logo_mobile.svg), replacing the full wordmark.
- `google.ico`: company icon downloaded unchanged from [Google](https://www.google.com/favicon.ico), replacing the monochrome approximation. Includes 16px and 32px images. Now using `google-lg.png` for the Playground display.

The other existing SVGs are retained. `bedrock.svg` is the AWS company logo, displayed with the label “AWS Bedrock”. Existing SVG sources are credited in the Playground footer to provider websites and Simple Icons.
